寶島 — 台灣日常生活的 AI 代理技能

統一發票對獎、YouBike 即時站點、台北垃圾車路線、官方天氣預報。
只用官方 API 與公開資料,免登入、免爬蟲,Claude Code、Codex 等編碼代理都能用。

開始安裝 GitHub 倉庫

01技能一覽

統一發票對獎 invoice-winning-numbers

從財政部電子發票整合服務平台公開頁面取得最新中獎號碼,附上對獎流程。

免登入

YouBike 站點即時查詢 youbike-realtime

台北市+新北市 YouBike 2.0 站點的可借車輛、可還空位即時數量。

免登入

台北市垃圾車路線 taipei-garbage

臺北市資料大平臺的垃圾清運路線 CSV:各里清運點與抵達時間。

免登入

中央氣象署天氣預報 cwa-weather

用 CWA 開放資料 API 查各縣市 36 小時與鄉鎮預報,官方資料。

免費即時發給 API 金鑰

台灣天氣查詢 taiwan-weather

用 Open-Meteo(免金鑰)查台灣各縣市現在天氣與未來預報,cwa-weather 的免金鑰備援。

免登入

02安裝

# 安裝全部技能
npx --yes skills add tahodev/baodao-skill --all -g

# 只安裝特定技能
npx --yes skills add tahodev/baodao-skill --skill invoice-winning-numbers -g

需要 Node.js 18 以上與 npx。支援 npx skills add 的編碼代理(Claude Code、Codex、OpenCode 等)都可以使用。

0330 天計畫

這個倉庫以「一天一技能」的速度成長中:國定假日、高鐵與台鐵時刻表、AQI、地震速報、匯率、停班停課公告⋯⋯都在候選清單上。進度與候選技能見 README 的 30 天計畫。

04設計原則

官方資料

只用官方 API 與公開資料集:財政部、臺北市資料大平臺、YouBike、中央氣象署、Open-Meteo。

免登入

不需要帳號、不需要 API 金鑰就能用(cwa-weather 使用免費、即時發給的金鑰)。

只查不寫

不改變外部狀態:不預約、不購買、不發文,只有查詢與計算。
