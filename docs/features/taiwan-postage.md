# taiwan-postage

中華郵政郵資表查詢。免金鑰，抓官網資費表頁面。

- 簡明國內函件資費表：https://www.post.gov.tw/post/internet/Postal/index.jsp?ID=2020106（2026-09-19 實測 200、約 224KB、UTF-8、6 張表）
- 實測重點：普通信函不逾 20 公克 8 元、明信片 5 元、郵簡 6 元、掛號費 +20、限時 +7
- 另有包裹/快捷/國際資費表頁面（ID=2030103、2010103、2020204 等）
- ID=2010104 是目錄頁非表格；資費會調整，以抓到的頁面為準並附查詢日期
- 國際件分區計費；不確定分區如實說並給連結

完整步驟請看 [SKILL.md](../../taiwan-postage/SKILL.md)。
