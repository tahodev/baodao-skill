# taiwan-suspension

天然災害停止上班上課官方公告。免金鑰，人事行政總處頁面。

- 來源：https://www.dgpa.gov.tw/typh/daily/nds.html（2026-09-19 實測 200、約 15KB、UTF-8）
- 含「無停班停課訊息」= 全國正常；有公告時逐字引用各縣市文字
- 全日公告通常前一日 19:00-22:00 發布；深夜問「明天」尚未公告就說還沒公告，不預測
- 散布不實停班停課訊息有刑事責任（頁面明列災防法 53 條）——絕不編造
- 僅政府機關與學校基準；民間公司放假由雇主決定
