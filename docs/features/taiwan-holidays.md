# taiwan-holidays

查台灣行政機關辦公日曆：國定假日、連假、補班日。免登入、免 API 金鑰。來源是行政院人事行政總處公告。

- 當年度（115 年＝2026 年）：官方 xlsx 月曆，放假日以紅字標示；python3 標準庫可解析，365 天全部驗證過（2026-09-12 實測）
- 114 年（2025）及更早：結構化 CSV（西元日期、星期、是否放假、備註），data.gov.tw 資料集 14718
- 2026 年平日放假日共 16 天：1/1、2/16-2/20（春節）、2/27、4/3、4/6、5/1、6/19、9/25、9/28、10/9、10/26、12/25
- 學校、銀行、股市休市日與行政機關日曆不同，請勿混用

完整解析程式、欄位說明與錯誤處理請看 [SKILL.md](../../taiwan-holidays/SKILL.md)。
