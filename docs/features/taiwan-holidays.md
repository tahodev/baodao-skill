# taiwan-holidays

查台灣行政機關辦公日曆：國定假日、連假、補班日。免登入、免 API 金鑰。來源是行政院人事行政總處公告。

- 主要方式：data.gov.tw 資料集 14718 的結構化 CSV，106-116 年全都有（含當年度 115 年與明年 116 年）；欄位 西元日期/星期/是否放假/備註（0=上班、2=放假、補班=補行上班）
- 114 年要用 114/10/20 更新版（新增教師節、光復節、行憲紀念日放假；該檔是 Big5 需 iconv），舊版會漏答 2025/9 之後的假日
- 備援/交叉驗證：當年度官方 xlsx 月曆，放假日以粉紅底色標示；python3 標準庫可解析，365 天結果與 CSV 完全一致（2026-09-12 實測＋渲染目視確認）
- 2026 年平日放假日共 16 天：1/1、2/16-2/20（春節）、2/27、4/3、4/6、5/1、6/19、9/25、9/28、10/9、10/26、12/25；114 下半年起官方廢除補班制度
- 學校、銀行、股市休市日與行政機關日曆不同，請勿混用

完整指令、編碼注意事項與錯誤處理請看 [SKILL.md](../../taiwan-holidays/SKILL.md)。
