# taiwan-oil-price

台灣中油每週牌價。免金鑰，抓官網歷史油價頁。

- 來源：https://www.cpc.com.tw/historyprice.aspx?n=2890（2026-09-19 實測 200、約 134KB、近 7 週，需瀏覽器 UA）
- 欄位：調價日期（民國年）、92/95/98 無鉛、超級/高級柴油
- 實測範例：115/09/14 當週 92=31.2、95=32.7、98=34.7、超柴=29.9 元/公升
- 週牌價每週一零時生效；無法預測下週漲跌，如實說明
- 更早歷史需分頁 POST（範圍外）；台塑牌價不同源

完整步驟請看 [SKILL.md](../../taiwan-oil-price/SKILL.md)。
