# taiwan-income-tax

綜合所得稅試算。免金鑰、純離線，免稅額、扣除額與課稅級距取自財政部公告，涵蓋 114、115 所得年度。

- 公告來源：https://gazette.nat.gov.tw/EG_FileManager/eguploadpub/eg031224/ch04/type3/gov30/num12/Eg.pdf（115 年度）、https://www.mof.gov.tw/singlehtml/384fb3077bb349ea973e7fc6f13b6974?cntId=e6bfc90ed42e42ccbcd83be96e331afc（114 年度）
- 2026-10-03 實測：單身、薪資 80 萬，115 年度綜合所得淨額 336,000、稅額 16,800；114 年度淨額 354,000、稅額 17,700
- 這是估算：列舉扣除、其他特別扣除、基本生活費差額、股利分開計稅、基本稅額與海外所得不在計算內
- 所得年度與申報年度差一年（114 年度所得在 2026 年 5 月申報）；年度不在表內時先查公告
