# postal-address

台灣 3 碼郵遞區號查詢與地址英譯（漢語拼音對照）。免登入、免 API 金鑰。來源是中華郵政官網下載區。

- 3 碼郵遞區號一覽表（各鄉鎮市區，Big5 純文字；另有經緯度 XML 版）
- 地址英譯三層對照：縣市鄉鎮（XML）、村里文字巷（TXT）、路街（TXT，743KB，115/01/16 更新）
- 全部檔案是 Big5 編碼，處理前先 `iconv -f big5 -t utf-8`
- 完整 3+3 六碼投遞區段沒有免登入的機讀全表（官方 Windows 程式或註冊 Web Service），需要六碼時導到官方查詢頁，不要自己猜
- 以上全部 2026-09-12 實測 HTTP 200

完整指令與錯誤處理請看 [SKILL.md](../../postal-address/SKILL.md)。
