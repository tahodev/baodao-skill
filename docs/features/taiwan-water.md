# taiwan-water

台灣自來水公司停水/降壓公告。免金鑰。

- JSON：https://web.water.gov.tw/wateroffapi/openData/export/json（2026-09-19 實測 200，當下 `[]` 無案件）
- CSV：https://web.water.gov.tw/wateroffapi/openData/export/csv-utf8（欄位：案件編號、區處、電話、起訖時間、類型、戶數、縣市、行政區、地區、原因…）
- **空清單 = 全國無停水公告**，不是錯誤
- 僅台水轄區；台北市屬北水處不在內；爆管突發可能來不及上公告 → 1910

完整步驟請看 [SKILL.md](../../taiwan-water/SKILL.md)。
