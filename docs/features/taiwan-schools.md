# taiwan-schools

教育部統計處校別資料：國中/國小的學校代碼、縣市鄉鎮、班級數、學生數。免金鑰。

- 國中（全年份單檔）：https://stats.moe.gov.tw/files/opendata/basej.csv（2026-09-19 實測 200、10,594 列、學年度 104-114）
- 國小（每年一檔）：https://stats.moe.gov.tw/files/detail/114/114_basec.csv（實測 200、2,663 校，103-114 可選）
- UTF-8 BOM；學年度 114 = 2025-08~2026-07，回報要換算
- 實測：私立淡江高中附設國小部（新北淡水 011301）
- 高中職/大專是別的檔名，本頁未收錄

完整步驟請看 [SKILL.md](../../taiwan-schools/SKILL.md)。
