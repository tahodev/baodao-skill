# taiwan-id-check

統一編號與身分證字號的檢查碼驗證。純本地計算，零網路、免金鑰。

- 統編：加權 1,2,1,2,1,2,4,1，乘積各位數相加，總和 %10==0 或 %5==0（第 7 位為 7 的特例，2026-09-19 實測 97176270 成立）
- 身分證：首字母對照表轉兩位數加權，含 I/O/W/Z/A 舊制對照；2026-09-19 實測 A123456789、B221003265 成立
- 測試向量（實測）：22099131、96979933、10458575 有效；竄改任一碼即失效
- 只驗格式與檢查碼，不代表該號碼真實存在；語意驗證（性別碼、字母對應）僅輔助

完整步驟請看 [SKILL.md](../../taiwan-id-check/SKILL.md)。
