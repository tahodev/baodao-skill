# taiwan-labor-health-insurance

受僱勞工每月自付的勞保（含就業保險）、健保保費，與雇主勞退提繳 6%。免金鑰、純離線，費率與級距為 115 年（2026 年 1 月 1 日起）適用。

- 勞保投保薪資分級表：https://www.bli.gov.tw/0005475.html；健保投保金額分級表：https://www.nhi.gov.tw/ch/cp-19422-c534e-2569-1.html
- 費率：勞保普通事故 11.5% 加就保 1%，勞工負擔 20%；健保 5.17%，勞工負擔 30%，眷屬最多計 3 口；勞退雇主 6%
- 2026-10-03 實測：程式算出的金額與公告分擔金額表一致（29,500 級：勞保 738、健保 458；313,000 級：健保 4,855）
- 只涵蓋一般受僱全時勞工；職災保險、補充保費、部分工時與職業工會不在範圍內
- 年度改變時級距會變，先查公告
