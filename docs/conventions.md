# 共同慣例（conventions）

多個技能重複用到的處理模式。各 SKILL.md 是查詢流程的正本；這裡收錄跨技能共通的轉換與習慣，寫新技能或除錯時先來這裡對一下。

## 民國年 ↔ 西元年

台灣官方資料常用民國年。換算：**西元 = 民國 + 1911**（115 → 2026）。

常見格式：

- `115/09/14`（中油歷史油價、台股 `115/09/01`）
- `1150921` yyyMMdd（中油 open data 的 `牌價生效日期`）
- `115.09.19`（台電 opendata 的發布時間，時段格式如 `115.09.19 03:10`）
- 學年度不是民國年：`114 學年度` = 2025 年 8 月到 2026 年 7 月（教育部 stats.moe.gov.tw 的檔名如 `114_basec.csv`）

## Big5 與編碼

政府老系統常見 Big5；**先判別再轉**：

- `.TXT` / `.txt`（中華郵政對照表、國圖館名錄）通常是 Big5：`iconv -f big5 -t utf-8`。
- `.xml`（中華郵政行政區經緯度）是 UTF-8：**不要**過 iconv，會轉壞。
- data.gov.tw 的 CSV 混 UTF-8 BOM 與 Big5（如人事總處日曆：115/116 是 UTF-8 BOM、114 更新版是 Big5），用 `file` 確認；CRLF 檔比對前先 strip `\r`。
- Python 讀 Big5：`open(p,'rb').read().decode('big5', errors='replace')`。

## curl 習慣

- 一律加 `-m 30`（大檔 60）與 `-s`；失敗隔幾秒重試 1~2 次，不要連續猛打。
- 政府網站偶爾擋預設 UA，帶 `-A 'Mozilla/5.0'` 較穩（中油歷史頁、健保署、國圖需要；中油 open data、多數 JSON API 不需要）。
- 回傳不是預期格式（空陣列、HTML 挑戰頁、非 JSON）時視為失敗，如實回報，不要用舊資料充數。
- 海外／機房 IP 可能被 Incapsula 之類依地區攔截（YouBike 統一 feed 實測）：換該技能的市府備援源，不要當成資料源失效。

## 時區

本倉庫的「今天」「本週」都是**台灣時間（UTC+8）**。節氣交節時刻、垃圾車排程、油價生效日都按台灣時間解讀；跨午夜前後的推算值（節氣 ±15 分鐘）如實標示誤差。
